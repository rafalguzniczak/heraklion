# Heraklion — nasz spacer

Prosty audioprzewodnik po Heraklionie: dziesięć nagrań MP3, punkty na mapie i czasy przejścia. Strona statyczna bez procesu budowania.

Publikacja: GitHub Pages z głównej gałęzi i katalogu `/` lub workflow Pages. Nagrania znajdują się w `audio/`.

Lokalnie: `python3 -m http.server 8000`, a potem otwórz `http://localhost:8000/`.
